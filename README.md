# Paragone

Paragone is a comprehensive fullstack application designed to help users manage their expenses by scanning and analyzing receipts. With modern technologies and an intuitive interface, Paragone makes financial management easier and more efficient.

## Key Features

- **Receipt Scanning**: Effortlessly scan receipts, with automatic extraction of key information using GPT.
- **Expense Categorization**: Automatically categorize expenses, providing better financial organization and analysis.
- **Financial Analysis**: Gain clear insights into your finances based on categorized expenses.
- **Data Export**: Export your expense data to CSV for further analysis or record-keeping.
- **Responsive Design**: Enjoy a fully responsive interface that ensures a seamless experience on all devices.

## Technologies Used

- **Frontend**: Developed with [Next.js](https://nextjs.org/) and styled using [Tailwind CSS](https://tailwindcss.com/).
- **Backend**: Powered by [Prisma](https://www.prisma.io/) and [PostgreSQL](https://www.postgresql.org/), offering robust data management and storage.

## Installation and Setup

### 1. Clone the repository:

```bash```
git clone https://github.com/yourusername/paragone.git

### 2. Navigate to the project directory:

cd paragone

### 3. Install dependencies:

npm install

### 4. Set up the environment variables:

Create a .env file in the root directory and add your environment variables, such as database connection details and API keys.

### 5. Run the development server:

npm run dev
